# One-Liner Marathon

One funny line, any subject: a night guard, his routine, and the motive
behind it — the twist lands in the last words and reframes the whole
routine as something darker.

`main.ts` (Node 22+, stdlib only) writes the single line to
`/output/entry.txt`, with a self-check that it is one non-blank line of
1–280 characters plus a read-back round-trip check. Run it with
`node main.ts`.
